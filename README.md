# NMR Spin-System Simulation

This project explores the quantum-mechanical description and simulation of coupled nuclear spin systems and NMR spectra using Python.

The project was completed collaboratively with my colleague Anton as part of our coursework in the Erasmus Mundus Master's programme in Theoretical Chemistry and Computational Modelling (TCCM).

## Topics Covered

- Nuclear spin states
- Pauli spin matrices
- Zeeman interaction
- Spin-spin (J) coupling
- Construction of spin Hamiltonians
- Kronecker products for multi-spin systems
- Hamiltonian diagonalization
- Eigenvalues and eigenvectors
- NMR transition frequencies
- Transition intensities
- Simulation and visualization of second-order NMR spectra
- Analysis of coupled AB spin systems

## Tools

- Python
- NumPy
- SymPy
- SciPy
- Matplotlib
- Jupyter Notebook

## Notebook

The main notebook is:

`NMR.ipynb`

It contains the construction and analysis of quantum-mechanical spin Hamiltonians, calculation of energy levels and allowed transitions, and simulation of NMR spectra.
